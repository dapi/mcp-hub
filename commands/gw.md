# Google Workspace CLI (`gw`)

Use the `gw` CLI at `~/.local/bin/gw` to interact with Google Workspace (Drive, Docs, Sheets) directly from bash. This is a standalone CLI generated by mcporter that talks to MCPHub's google_workspace server.

## Prerequisites

- MCPHub must be running (`make status` in ~/code/mcp-hub)
- Default email: `danilpismenny@gmail.com` — always pass as `--user-google-email`

## Quick Reference

### Google Drive

```bash
# Search files
gw google-workspace-search-drive-files --user-google-email danilpismenny@gmail.com --query "search terms"

# List files in folder (root by default)
gw google-workspace-list-drive-items --user-google-email danilpismenny@gmail.com

# List files in specific folder
gw google-workspace-list-drive-items --user-google-email danilpismenny@gmail.com --folder-id FOLDER_ID

# Read file content
gw google-workspace-get-drive-file-content --user-google-email danilpismenny@gmail.com --file-id FILE_ID

# Download file (returns local path or URL)
gw google-workspace-get-drive-file-download-url --user-google-email danilpismenny@gmail.com --file-id FILE_ID

# Create folder
gw google-workspace-create-drive-folder --user-google-email danilpismenny@gmail.com --folder-name "Name" --parent-folder-id PARENT_ID

# Create file
gw google-workspace-create-drive-file --user-google-email danilpismenny@gmail.com --file-name "Name" --mime-type "text/plain" --content "content"

# Copy file
gw google-workspace-copy-drive-file --user-google-email danilpismenny@gmail.com --file-id FILE_ID --new-name "Copy Name"

# Share file
gw google-workspace-share-drive-file --user-google-email danilpismenny@gmail.com --file-id FILE_ID --share-with-email someone@example.com --role reader

# Get shareable link
gw google-workspace-get-drive-shareable-link --user-google-email danilpismenny@gmail.com --file-id FILE_ID

# Check permissions
gw google-workspace-get-drive-file-permissions --user-google-email danilpismenny@gmail.com --file-id FILE_ID
```

### Google Docs

```bash
# Search docs
gw google-workspace-search-docs --user-google-email danilpismenny@gmail.com --query "search terms"

# Get doc content (plain text)
gw google-workspace-get-doc-content --user-google-email danilpismenny@gmail.com --document-id DOC_ID

# Get doc as markdown
gw google-workspace-get-doc-as-markdown --user-google-email danilpismenny@gmail.com --document-id DOC_ID

# Create doc
gw google-workspace-create-doc --user-google-email danilpismenny@gmail.com --title "Title" --content "Body text"

# Create doc in folder
gw google-workspace-create-doc --user-google-email danilpismenny@gmail.com --title "Title" --content "Body" --folder-id FOLDER_ID

# Edit doc text
gw google-workspace-modify-doc-text --user-google-email danilpismenny@gmail.com --document-id DOC_ID --raw '{"operations": [{"action": "insert", "text": "Hello", "index": 1}]}'

# Find and replace
gw google-workspace-find-and-replace-doc --user-google-email danilpismenny@gmail.com --document-id DOC_ID --find "old" --replace "new"

# Export doc to PDF
gw google-workspace-export-doc-to-pdf --user-google-email danilpismenny@gmail.com --document-id DOC_ID
```

### Google Sheets

```bash
# List spreadsheets
gw google-workspace-list-spreadsheets --user-google-email danilpismenny@gmail.com

# Get spreadsheet info (sheets, metadata)
gw google-workspace-get-spreadsheet-info --user-google-email danilpismenny@gmail.com --spreadsheet-id SHEET_ID

# Read values
gw google-workspace-read-sheet-values --user-google-email danilpismenny@gmail.com --spreadsheet-id SHEET_ID --range "Sheet1!A1:D10"

# Write values
gw google-workspace-modify-sheet-values --user-google-email danilpismenny@gmail.com --spreadsheet-id SHEET_ID --range "Sheet1!A1" --raw '{"values": [["a","b"],["c","d"]]}'

# Create spreadsheet
gw google-workspace-create-spreadsheet --user-google-email danilpismenny@gmail.com --title "Title"

# Add new sheet tab
gw google-workspace-create-sheet --user-google-email danilpismenny@gmail.com --spreadsheet-id SHEET_ID --sheet-title "Tab Name"

# Format range
gw google-workspace-format-sheet-range --user-google-email danilpismenny@gmail.com --spreadsheet-id SHEET_ID --range "Sheet1!A1:D1" --raw '{"bold": true}'
```

### Comments (Docs & Sheets)

```bash
# Read comments on a doc
gw google-workspace-read-document-comments --user-google-email danilpismenny@gmail.com --document-id DOC_ID

# Add comment to doc
gw google-workspace-create-document-comment --user-google-email danilpismenny@gmail.com --document-id DOC_ID --comment "Comment text"

# Reply to comment
gw google-workspace-reply-to-document-comment --user-google-email danilpismenny@gmail.com --document-id DOC_ID --comment-id COMMENT_ID --reply "Reply text"

# Resolve comment
gw google-workspace-resolve-document-comment --user-google-email danilpismenny@gmail.com --document-id DOC_ID --comment-id COMMENT_ID

# Same pattern for spreadsheets: read-spreadsheet-comments, create-spreadsheet-comment, etc.
```

## Usage Pattern

1. Always pass `--user-google-email danilpismenny@gmail.com`
2. For complex arguments use `--raw '{"key": "value"}'`
3. File/folder IDs come from search or list commands — run those first
4. If auth fails, run: `gw google-workspace-start-google-auth --service-name drive`

## All Commands

Drive: search-drive-files, get-drive-file-content, get-drive-file-download-url, list-drive-items, create-drive-folder, create-drive-file, import-to-google-doc, get-drive-file-permissions, check-drive-file-public-access, update-drive-file, get-drive-shareable-link, share-drive-file, batch-share-drive-file, update-drive-permission, remove-drive-permission, copy-drive-file, transfer-drive-ownership, set-drive-file-permissions

Docs: search-docs, get-doc-content, list-docs-in-folder, create-doc, modify-doc-text, find-and-replace-doc, insert-doc-elements, insert-doc-image, update-doc-headers-footers, batch-update-doc, inspect-doc-structure, create-table-with-data, debug-table-structure, export-doc-to-pdf, update-paragraph-style, get-doc-as-markdown

Sheets: list-spreadsheets, get-spreadsheet-info, read-sheet-values, modify-sheet-values, format-sheet-range, add-conditional-formatting, update-conditional-formatting, delete-conditional-formatting, create-spreadsheet, create-sheet

Comments: read-document-comments, create-document-comment, reply-to-document-comment, resolve-document-comment, read-spreadsheet-comments, create-spreadsheet-comment, reply-to-spreadsheet-comment, resolve-spreadsheet-comment

All commands are prefixed with `google-workspace-` when calling via `gw`.
